User does their own git commits and pushes. Do not run `git add`, `git commit`, or `git push` commands.

**Why:** User prefers to control what goes into commits and when changes are pushed.

**How to apply:** After making file edits, stop there. Do not attempt to stage, commit, or push the changes. The user will handle that themselves.
