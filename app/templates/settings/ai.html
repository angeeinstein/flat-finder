About AI extraction

When Ollama is running, each imported listing is processed in the background to extract extra fields:

  • Pets allowed, internet included
  • Elevator, renovation status, WG-suitability
  • Key money (Ablöse), lease type
  • Year built, laundry available
  • German summary (optional)

Extraction runs as a background job after import. Fields already found by the parser are never overwritten.

Tips

Installing a model takes several minutes and requires enough disk space. After pulling, refresh this page and set it as active. The pull runs in the background via the RQ worker — check Failed Jobs if something goes wrong.
